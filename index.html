# 🚗 Plaka Doğrulama Uygulaması — Tam Proje Promptu ## 📋 PROJE TANIMI Türkiye'deki araç sahiplerine yönelik, bir araç plakasının **APP (standart dışı)** mi yoksa **orijinal (yasal)** mı olduğunu fotoğraf yükleyerek tespit eden, full-stack bir web uygulaması ve mobil-uyumlu site geliştir. --- ## 🎯 TEMEL AMAÇ Kullanıcılar araçlarının plaka fotoğrafını yükleyecek; uygulama bu fotoğrafı analiz ederek: - Plakanın **APP mi / Orijinal mi** olduğunu tespit edecek - Tespit nedenlerini **madde madde ve görsel** olarak açıklayacak - **Yasal uyarı ve ceza bilgisi** sunacak - **Ne yapılması gerektiği** konusunda yönlendirme sağlayacak --- ## 🏗️ TEKNİK MİMARİ ### Frontend (React + TypeScript + TailwindCSS) ``` /frontend /src /components - Response: { totalAnalysis: number, appRate: number, todayCount: number } ``` --- ## 📊 VERİTABANI ŞEMASI (PostgreSQL / Supabase) ```sql -- Analizler tablosu CREATE TABLE plate_analyses ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), image_url TEXT, image_hash TEXT UNIQUE, -- Aynı fotoğrafın tekrar analizini önle verdict VARCHAR(10) CHECK (verdict IN ('ORIGINAL', 'APP')), overall_confidence DECIMAL(5,2), risk_level VARCHAR(10), criteria_results JSONB, summary TEXT, recommendation TEXT, processing_time_ms INTEGER, ip_address INET, -- Rate limiting için created_at TIMESTAMPTZ DEFAULT NOW() ); -- İstatistikler view'i CREATE VIEW analysis_stats AS SELECT COUNT(*) as total_analyses, COUNT(*) FILTER (WHERE verdict = 'APP') as app_count, COUNT(*) FILTER (WHERE verdict = 'ORIGINAL') as original_count, ROUND(COUNT(*) FILTER (WHERE verdict = 'APP')::DECIMAL / COUNT(*) * 100, 1) as app_rate, AVG(processing_time_ms) as avg_processing_ms FROM plate_analyses; ``` --- ## 📱 MOBİL UYGULAMA GEREKSİNİMLERİ (React Native / Expo) ``` /mobile /screens -
